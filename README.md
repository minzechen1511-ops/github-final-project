# Simple Interest Calculator

This repository contains the final project files for the Introduction to Git and GitHub assignment.

## Project Name

Simple Interest Calculator

## Project Details

The project provides a Bash script named `simple-interest.sh` that calculates simple interest from user input.

The calculator asks for:

- Principal amount
- Rate of interest
- Time period

It then computes simple interest using:

```text
Simple Interest = Principal x Rate x Time / 100
```
